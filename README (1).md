# 🛒 Shopping Trends Analytics Dashboard

Dashboard interaktif untuk menganalisis tren belanja dan memprediksi jumlah pembelian pelanggan menggunakan Machine Learning.

## 📊 Model yang Digunakan
- **Linear Regression**
- **Random Forest**
- **XGBoost**

## 🚀 Cara Deploy ke Streamlit Cloud

1. Upload semua file ke repository GitHub Anda
2. Buka [share.streamlit.io](https://share.streamlit.io)
3. Hubungkan repo GitHub → pilih `app.py` sebagai main file
4. Klik **Deploy**

## 📁 Struktur File
```
├── app.py
├── requirements.txt
├── shopping_trends-selected-columns.csv
└── README.md
```

## ⚙️ Menjalankan Secara Lokal
```bash
pip install -r requirements.txt
streamlit run app.py
```
